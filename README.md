# 萬用回應SOP產生器

輸入事件，產生 SOP 回應圖片。

純 HTML、CSS、JavaScript 製作，無需安裝套件或後端。直接開啟 `index.html` 即可使用。

網站：https://mtwmt.com/sop/

## 功能

- 輸入事件、產生回應
- 預覽產生的圖片
- 複製文字、下載 PNG
